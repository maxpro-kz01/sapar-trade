ПРОВЕРКА ПОДКЛЮЧЕНИЯ К 1С — Sapar Trade
==========================================
Что делаем: проверяем, что программа-агент может ЧИТАТЬ данные из вашей базы 1С (srv1c / utp).
В 1С ничего не меняется. Интернет и наш сервер на этом шаге не нужны.
Время: 20-30 минут. Делает администратор 1С или тот, кто имеет доступ к серверу srv1c.

ШАГ 0. Резервная копия базы 1С
  Конфигуратор -> Администрирование -> Выгрузить информационную базу (.dt). Сохраните файл.

ШАГ 1. Пользователь 1С только для чтения
  Конфигуратор -> Администрирование -> Пользователи -> Добавить:
    Имя: sapar_api
    Аутентификация 1С:Предприятия, придумайте пароль (запишите его)
    Роли: права на просмотр данных + право внешнего соединения
          (обычно роль для просмотра/«только чтение» и «Право внешнего соединения» — названия зависят от базы)
  Проверьте: войдите в 1С под sapar_api — должны открываться справочники и отчёты,
  но провести или изменить документ нельзя.

ШАГ 2. Регистрация COM-компоненты 1С (на сервере srv1c)
  Откройте командную строку ОТ ИМЕНИ АДМИНИСТРАТОРА и выполните:
    regsvr32 "C:\Program Files\1cv8\8.3.23.2040\bin\comcntr.dll"
  Должно появиться сообщение «успешно». Если 1С 32-битная — путь: C:\Program Files (x86)\1cv8\8.3.23.2040\bin\comcntr.dll

ШАГ 3. Папка агента
  Распакуйте архив в C:\SaparTrade\agent  (на сервере srv1c)

ШАГ 4. Сохранить пароль
  Дважды щёлкните  1_save-password.bat
    - введите пароль пользователя sapar_api из шага 1
    - ключ агента пока НЕ нужен — просто нажмите Enter
  Пароль сохраняется зашифрованным, только для текущего пользователя Windows.

ШАГ 5. Проверка
  Дважды щёлкните  2_check-1c.bat
    - должно быть «1С: OK ...»
    - затем 1-3 минуты идёт диагностика
    - откроется папка, в ней появится файл  probe-ГГГГММДД-ЧЧММ.txt

ШАГ 6. Отправьте файл probe-....txt разработчику (сюда, в чат).
  В файле нет паролей: только названия полей 1С, по 5 строк из каждой выгрузки и количество строк.
  По нему я сверю запросы с вашей базой и поправлю, если что-то называется иначе.

ЕСЛИ ОШИБКА
  «Класс не зарегистрирован» / V83.COMConnector  -> повторите шаг 2 (от администратора)
  «Неправильное имя или пароль» / «Идентификация пользователя не выполнена» -> проверьте пароль, повторите шаг 4
  «Нет прав на внешнее соединение» -> добавьте пользователю sapar_api право внешнего соединения (шаг 1)
  «Нет свободной лицензии» -> закройте лишнюю 1С у кого-нибудь и повторите
  Любая другая — сфотографируйте окно или пришлите файл из папки logs
