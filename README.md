# Sapar Trade — прототип системы управления

Кликабельный прототип для ИП «Sapar Trade» (г. Кызылорда): клиентское приложение, админ-панель со сменами и отчётом директору в WhatsApp, приложение торгового представителя и система управления по ТЗ V1.0 (8 ролей, дашборды, Score ТП, GPS экспедиторов, склад, дебиторка, P&L, задачи, AI). Языки RU / ҚАЗ.

> ⚠️ Демо-версия: данные вымышленные и не сохраняются, сервера и базы нет. Пароли ниже — только для демонстрации.

## Структура
| Путь | Что |
|---|---|
| `public/index.html` | Прототип (публикуется на Render как статический сайт) |
| `src/` | Тот же код, разбитый на 27 модулей по разделам (см. `src/README.md`) |
| `docs/` | ТЗ (KZ/RU), статус, архитектура, схема БД, API, справочник, промт для продолжения |
| `render.yaml` | Настройки Render |

## Демо-доступ
Двойной тап по логотипу на экране входа → меню сотрудников.
- Администратор: `admin` / `admin`
- Торговый представитель: `agent` / `agent123`
- Система управления: пароль `1234`, для владельца и директора код 2FA `2026`

## Деплой
Render, статический сайт, публикуется папка `public/`, автодеплой при пуше в `main`.
