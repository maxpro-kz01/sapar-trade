# Исходники прототипа по модулям

**Это исходники сайта.** Правки вносятся здесь, затем `npm run build` собирает `public/index.html`.
Модули — один глобальный скрипт (React 18 UMD), они **не импортируют** друг друга; порядок склейки задан в `modules.json` (ниже — исходный список; новые модули `00_core/use_media.js` и `00_core/layout_shell.jsx` идут сразу после `ui_components.jsx`):

|---|---|---|---|

| 2 | `01_data/mock_data.jsx` | Демо-данные: категории, товары, баннеры, сторис, заказы, счета, аудит, ТП | 116 |
