# ТЗ: кнопка «Назад» браузера и телефона внутри сайта

Версия 1.0 · 17.11.2026 · статус: утверждено 17.11, сделано

## Проблема
Сайт — одна страница: вкладки и экраны переключаются без смены адреса, браузер не знает о переходах.
Поэтому «Назад» (в браузере, жест «назад» или системная кнопка на Android) **сразу уходит с сайта** — на предыдущий сайт или пустую вкладку.

## Как должно работать
| Где | Что сейчас на экране | «Назад» делает |
|---|---|---|
| Любое окно поверх экрана (уведомления, смена пароля, новый сотрудник, план продаж, новая задача, отчёт смены, подтверждение заказа ТП) | открыто окно | **закрывает окно**, экран под ним остаётся |
| Система управления | вкладка (Продажи, Команда, Клиенты…) или карточка внутри вкладки (ТП, клиент) | возвращает на **предыдущую вкладку/карточку** — как было открыто, с тем же периодом |
| Админ-панель | вкладка (Заказы, Склад, Сотрудники, Настройки) | предыдущая вкладка |
| Приложение ТП | заказ по магазину → «Мои магазины» → «Мои заказы» | шаг назад: из заказа — к списку магазинов и т.д. Корзина каждого магазина **сохраняется**, пока открыт сайт: вернулись в магазин — товары на месте; после отправки заказа корзина очищается |
| Экран входа | форма логина | к «Вход для сотрудников» |
| Первый экран после входа (Главная / первая вкладка) | — | **остаётся на сайте** (не выкидывает на чужую страницу). Выход — только кнопкой «Выйти» |
| Водитель в рейсе | экран рейса | остаётся на экране рейса (случайное «Назад» не должно прерывать передачу GPS) |

Дополнительно:
- Кнопка «Вперёд» браузера возвращает обратно.
- После обновления страницы (F5) открывается та же вкладка, где был сотрудник.
- Вход и выход **заменяют** запись в истории: после входа «Назад» не возвращает на форму логина, после выхода — не возвращает в систему.

## Как сделать (технически)
- Новый модуль `src/00_core/nav_history.js`: хук `useNavState(ключ, начальное)` — состояние экрана хранится в истории браузера
  (`history.pushState` / событие `popstate`); хук `useBackClose(открыто, закрыть)` — окно закрывается «Назадом».
- `Modal` (общий для всех окон) сам подключает `useBackClose` — все 10 окон получают поведение сразу.
- Переводятся на `useNavState`: выбор экрана в корне сайта (вход/система), вкладка+карточка в Системе управления, вкладка админ-панели,
  вкладка и магазин в приложении ТП. Период («Этот месяц» и т.д.) — не отдельный шаг истории, но сохраняется при возврате.
- Корень после входа — «защитная» запись: «Назад» с первого экрана не уходит с сайта.

## Проверка
- Автотест в браузере `tools/back-shots.mjs` (25 проверок): для каждого раздела — открыть 2–3 вкладки/карточку/окно, нажать «Назад» → правильный экран,
  «Вперёд» → снова тот же; окно закрывается «Назадом»; с первого экрана «Назад» не уходит с сайта; после входа «Назад» не показывает логин.
- Все прежние проверки (сервер 60, браузерные) — без ошибок.
