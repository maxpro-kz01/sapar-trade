# ТЗ: выбор товара и подарка из списка (форма «Новая акция»)

Версия 1.0 · 21.11.2026 · модуль `src/08_admin/admin_promos.jsx`

## Цель
Владелец и директор создают акцию (купи N — получи подарок) без набора названия товара вручную.

## Решения (согласованы с владельцем)
1. Поля «Товар, который нужно купить» и «Подарок» работают как выпадающий список: нажатие на поле раскрывает список всех товаров.
2. Товары сгруппированы по группам 1С (заголовок группы, внутри — по алфавиту). У каждого показан остаток на складе.
3. Сверху строка поиска по названию; печатать не обязательно.
4. В подарок можно выбрать любой товар. Товар без остатка показывается серым с пометкой «нет на складе», но выбрать его можно.
5. Выбранный товар показывается карточкой: название, остаток, «нажмите, чтобы заменить» и крестик «сбросить».
6. Список показывает первые 300 позиций, если их больше — подсказка «введите часть названия».

## Не меняется
Сервер, база, правила расчёта подарка, предупреждение о нехватке подарка на складе.

## Проверка
Автотест в браузере: список открывается, выбор товара работает, карточка выбранного показывается, ошибок в консоли нет.
