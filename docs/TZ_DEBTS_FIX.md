# ТЗ: исправление расчёта долгов клиентов (оплаты не вычитались)

Версия 1.0 · 17.11.2026 · статус: утверждено 17.11, сделано (тесты server/test/debts.test.js)

## Что нашли
Заказчик сравнил с 1С:Бухгалтерией (ОСВ по счёту 1274, ноябрь 2026): у группы «Жасулан Шиели» долг на конец — **4 197 150 ₸**,
а в программе у ТП Жасулана — **свыше 32 млн ₸**. Всего по программе долг 770 млн, просрочено 728 млн — нереально много.

**Причина — ошибка в программе (с 09.11, ТЗ финансов v1.2, часть F).** Долг загружается из 1С по документам:
- отгрузка (реализация) → **плюс** (клиент должен);
- оплата (приходный кассовый ордер, поступление на счёт, Kaspi) часто записана **отдельным документом** → **минус**.

Программа суммировала только плюсы (`amount > 0`) и **не вычитала оплаты**. До 09.11 долг шёл одной строкой на клиента — оплаты вычитались сами.

## Как правильно
Для каждого клиента:
1. **Долг клиента = все плюсы − все минусы** (как сальдо в 1С). Если получилось ноль или меньше — долга нет (переплата/аванс).
2. **Возраст долга — по правилу «оплата закрывает самые старые отгрузки»** (FIFO): оплаты гасят отгрузки, начиная с самой старой;
   неоплаченными остаются самые новые. Просрочено — только то, что осталось неоплаченным и старше 14 дней.
3. Долг без документа (начальные остатки) — тоже гасится оплатами первым (как самый старый).

Пример: отгрузки 10.10 — 100 000, 20.10 — 50 000, 05.11 — 30 000; оплаты −120 000.
Долг = 60 000: от 20.10 осталось 30 000 (просрочено), от 05.11 — 30 000 (если старше 14 дней — просрочено).

## Где исправить (одно место для всех экранов)
- Миграция 006: представление базы `onec_debts_open` — неоплаченные части документов по правилу выше.
- Все расчёты переходят на него: Главная (дебиторка, просрочка), Клиенты (долг, возраст долга, список должников),
  Команда (долг и просрочка по ТП), Проблемы и колокольчик, отчёт смены.
- Данные из 1С заново грузить не нужно — цифры пересчитаются сразу после выкладки.

## Проверка
- Автотесты: пример выше; клиент с переплатой — долга нет; оплата без документа; сумма «по возрасту» = долгу клиента;
  итог по ТП = сумме его клиентов.
- Сверка с заказчиком: группа «Жасулан Шиели» и 2–3 клиента из ОСВ 1274 — суммы должны совпасть с 1С (или различаться
  только на то, что есть в Бухгалтерии, но не в УТП — тогда это покажет сверка, см. ниже).

## Важно: УТП и Бухгалтерия — разные базы
Программа берёт долги из **УТП** (управленческий учёт). ОСВ — из **Бухгалтерии**. Если какие-то оплаты вносятся только в Бухгалтерию,
суммы будут отличаться и после исправления. Тогда — следующий шаг: брать долги из Бухгалтерии (счёт 1274) через того же агента.
