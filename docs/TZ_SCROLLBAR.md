# ТЗ: видимый ползунок прокрутки (v1.0)

Цель: на компьютере у длинных списков справа виден ползунок, его можно взять мышью и тянуть.

- Где: один общий стиль в `src/00_core/root_app.jsx` (действует во всём приложении).
- Компьютер (мышь, `pointer: fine`): полоса 12px, серо-фиолетовый ползунок, темнее при наведении.
- Телефон/планшет (палец, `pointer: coarse`): полоса скрыта, как раньше (прокрутка пальцем).
- Firefox: `scrollbar-color`.
- Горизонтальные ленты-чипы со `scrollbarWidth: none` не меняются.
- Проверка: Playwright, ширина полосы у списка клиентов = 12px.
