# ТЗ: GPS водителей в фоне через Traccar Client (этап 2)

Версия 1.0 · 19.11.2026 · решение заказчика: оба варианта — страница водителя на сайте (этап 1) остаётся, плюс готовое приложение Traccar Client для работы в фоне.

## Зачем
Страница на сайте передаёт место, только пока она открыта и экран включён. Traccar Client (бесплатное приложение, Google Play / App Store) работает в фоне: экран заблокирован, браузер свёрнут.

## Как работает
1. Владелец/директор/админ открывает «Сотрудники» → водитель → **«GPS-приложение»**: видит адрес сервера и личный ключ водителя (можно выпустить новый — старый перестаёт работать).
2. Водитель ставит Traccar Client, вводит **идентификатор устройства = ключ** и **адрес сервера**, включает «Служба».
3. Первая пришедшая точка автоматически начинает рейс. Если от приложения нет точек **30 минут** — рейс закрывается сам (на время последней точки).
4. Водитель выключил службу в приложении — место не передаётся (как «Завершить рейс»).
5. Карта «Экспедиторы», маршрут за день, километры и «нет сигнала > 5 мин» — те же, что в этапе 1.

## Сервер
- Миграция 011: `users.gps_key` (уникальный, у водителей), `trips.source` ('web' / 'traccar').
- `GET|POST /api/fleet/traccar` — без входа по паролю, водитель определяется по ключу. Форматы: OsmAnd-запрос (id, lat, lon, timestamp, speed в узлах, bearing, hdop/accuracy) и JSON нового Traccar Client (device_id, location.coords…). Всегда отвечает 200 пустым телом на валидную точку; неверный ключ — 401.
- `GET /api/fleet/gps-keys` (право «users») — водители, ключи, адрес сервера; `POST /api/fleet/gps-keys/:id` — выпустить/заменить ключ. Запись в журнале действий.
- Если у водителя открыт рейс с сайта — точки Traccar идут в него; иначе создаётся рейс source='traccar'.
- Проверки точек те же (cleanPoint): диапазоны, не из будущего, не старше суток, без дублей. Ключ не логируется.
- Ограничение частоты: 120 запросов в минуту с одного IP.

## Критерии приёмки (автотесты)
- Точка по ключу создаёт рейс и видна на карте; повтор той же точки не дублируется.
- Неверный/пустой ключ, ключ неактивного пользователя или не водителя — 401, ничего не сохраняется.
- OsmAnd-параметры: скорость узлы → м/с; JSON-формат разбирается.
- Рейс Traccar без точек 30 минут закрывается; следующая точка открывает новый.
- Ключи видят/выпускают только роли с правом «users»; ключ нового выпуска меняет старый.

## Установка у водителя (Android)
Traccar Client → идентификатор устройства: ключ; адрес сервера: из карточки; частота 30 с; точность «высокая»; разрешение на геолокацию «всегда»; отключить оптимизацию батареи для приложения.
iPhone: приложение есть, но iOS ограничивает фон — на iPhone надёжнее страница сайта, открытая на экране.
