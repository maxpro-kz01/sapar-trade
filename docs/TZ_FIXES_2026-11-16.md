# ТЗ: исправления по проверке 16.11.2026

Версия 1.0 · 16.11.2026 · утверждено заказчиком (ответы 16.11)

## 1. Плашка «Данные устарели» горит, даже когда агент работает
**Причина.** Сервер считает устаревшим любой вид данных старше 15 минут. Но по расписанию агента товары, клиенты и ТП клиентов
приходят раз в час, склады и статьи денег — раз в сутки. Значит, плашка не гаснет никогда.

**Решение.**
- У каждого вида данных — свой интервал (как в расписании агента): остатки, цены, продажи, себестоимость, долги, деньги, движение денег — 5 мин;
  товары, клиенты, ТП клиентов — 60 мин; склады, статьи денег — раз в сутки.
- «Устарело» = нет загрузки дольше, чем `max(15 мин, 2 × интервал + 10 мин)`.
- «Обновлено: …» на плашке и в карточках — время самой старой из частых выгрузок (каждые 5 мин), а не суточных.
- На экране «Интеграция 1С» у каждой строки видно, как часто она должна обновляться.
- Тесты: суточная выгрузка трёхчасовой давности — не устарела; остатки 20-минутной давности — устарели.

## 2. 6_autostart.bat сразу закрывается
**Причина.** При перезапуске с правами администратора Windows неправильно разбирает путь с пробелами («Sapar Trade Programs») — окно закрывается.

**Решение.**
- `install-task.ps1` сам проверяет права и, если их нет, перезапускает себя от администратора в окне PowerShell, которое **не закрывается** (видно результат или ошибку).
- Пользователь Windows по умолчанию — тот, кто запустил (вводить имя не нужно; спрашивается только пароль).
- `6_autostart.bat` просто вызывает `install-task.ps1`.

## 3. Сайт показывает старую версию после обновления
**Решение.**
- При сборке в страницу записывается номер версии (коммит GitHub на Render).
- Сайт раз в 5 минут (и при возвращении на вкладку) проверяет, не вышла ли новая версия; если вышла — внизу экрана
  плашка «Вышла новая версия сайта» с кнопкой «Обновить». Введённые данные (корзина ТП, рейс водителя) не теряются:
  очередь GPS хранится на телефоне, сессия — во вкладке.
- В локальной сборке проверка выключена.
