## 3. ИЗВЕСТНЫЕ ПРОБЛЕМЫ ПРОТОТИПА
1. **Логотип не отображается** — строка `LOGO_BADGE_SRC` (base64) повреждена (длина 24021 — не кратна 4). Нужен исходный файл логотипа от заказчика.
2. Все пароли демо и видны в коде: админ `admin/admin`, ТП `agent/agent123`, система управления `1234` + 2FA `2026`.
3. Данные не сохраняются: после перезагрузки страницы всё сбрасывается (нет сервера/БД).
4. Перевод на казахский работает через подмену текста на странице (MutationObserver). В настоящем проекте заменить на i18n-ключи (`react-i18next`), словарь перенести в `ru.json` / `kk.json`.
5. Один HTML на 360 КБ с Babel в браузере — медленный старт на слабых телефонах; в проекте собирать через Vite.
6. GPS в браузере работает только пока приложение открыто на экране (ограничение iOS/Android).
