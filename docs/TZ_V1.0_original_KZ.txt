SAPAR TRADE БІРЫҢҒАЙ БАСҚАРУ ЖҮЙЕСІ

**Программистке арналған техникалық тапсырма  V1.0**

*Компания атауы: Sapar Trade*

Құжат Sapar Trade компаниясының бірыңғай басқару, аналитика және бақылау жүйесіне қойылатын функционалдық, интеграциялық және қауіпсіздік талаптарын белгілейді.

# 1. Жобаның мақсаты

Sapar Trade компаниясының жұмысын бір жерден басқаруға арналған iOS, Android және Web жүйесін әзірлеу. Иесі сатылымды, валовая прибыльді, маржаны, таза пайданы, шығындарды, дебиторканы, ақша қозғалысын, қойма қалдығын, қайтарымды және қызметкерлердің тиімділігін нақты уақытта көруі тиіс. Негізгі қағида: басшы 1–2 минут ішінде компанияның жағдайын түсінуі керек.

# 2. Жүйенің құрылымы

A. Компания иесіне арналған мобильді қосымша. B. Қызметкерлерге арналған рөлдік мобильді қосымша. C. Компания иесі, директор және әкімшіге арналған Web Admin Panel. Барлық клиенттер бір Backend API арқылы жұмыс істейді.

# 3. Рөлдер және қолжетімділік

Рөлдер: Owner, директор по продажам, супервайзер, торговый представитель, водитель-экспедитор, склад қызметкері, завсклад, бухгалтер, финансист, администратор. Рұқсаттар жеке бапталады және Backend/API деңгейінде тексеріледі.

# 4. Қаржылық құқықтардың соңғы ережесі

Owner: выручка, себестоимость, валовая прибыль, маржа, шығындар, таза пайда және барлық операциялық KPI. Директор: сатылым, план/факт, маржа, дебиторка, возврат, клиенттер, ТП және супервайзерлер; валовая прибыль мен таза пайданы көрмейді. Супервайзер мен ТП: тек операциялық KPI; валовая прибыль, маржа, таза пайданы көрмейді. Водитель, склад және өзге қызметкерлер тек жұмысына қажет операциялық ақпаратты көреді.

# 5. Owner Dashboard

Басты экран: выручка, валовая прибыль, валовая маржа, операциялық шығындар, таза пайда, таза рентабельность, түскен ақша, дебиторка, просроченная дебиторка, қоймадағы тауар сомасы, возврат және сату жоспары. Бұл толық қаржылық экран тек Owner үшін.

# 6. Уақыт және салыстыру фильтрлері

Фильтрлер: бүгін, кеше, осы апта, өткен апта, осы ай, өткен ай, квартал, жыл, өткен жыл және еркін дата. Әр көрсеткіш алдыңғы кезеңмен салыстырылады: сома, пайыздық өсім немесе төмендеу.

# 7. Сату бөлімі Dashboard

Жалпы жоспар, факт, орындалу пайызы, қалдық сома, күндік темп, ай соңындағы болжам, валовая прибыль, маржа, возврат, дебиторка, белсенді/жаңа/жоғалған клиенттер, заказ берген және бермеген клиенттер. Директор валовая прибыль мен таза пайданы көрмейді.

# 8. Торговый представитель модулі

ТП карточкасы: аты-жөні, команда, супервайзер, территория, маршрут, бастау/аяқтау уақыты, жұмыс сағаты, километр, жоспар/факт нүктелер, заказ берген/бермеген дүкендер, тиімді визит, сату, жоспар, SKU, орташа чек, возврат, дебиторка, просрочка, жаңа клиент және GPS маршрут.

# 9. ТП Score және рейтинг

Score 0–100: сату жоспары 35, эффективный визит 20, маршрут 15, возврат 10, дебиторка тәртібі 10, SKU 5, дисциплина 5. Салмақтар Admin Panel-де өзгертіледі. Рейтинг күндік, апталық, айлық, кварталдық; құпия қаржылық деректерді көрсетпейді.

# 10. Супервайзер модулі

Командадағы ТП саны, команда продажасы, жоспар, тиімді визит, возврат, дебиторка, просрочка, жаңа/жоғалған клиенттер және орташа KPI көрсетіледі. Екі супервайзер командасын салыстыру мүмкін. Маржа, валовая және таза пайда көрсетілмейді.

# 11. GPS және маршрут

Жұмыс уақыты ішінде: бастау нүктесі, дүкендер, келу/кету уақыты, ұзақтығы, заказ және сома, жүрілген маршрут, ауытқу. GPS тек бекітілген жұмыс уақыты мен қызметтік маршрут шегінде қолданылады.

# 12. Водитель экспедитор және жеткізу

Маршрут, нүктелер, шығу/қайту уақыты, км, жеткізілген/қайтарылған тауар, жиналған ақша, қолма-қол, банк төлемдері, дебиторка, накладная және GPS. Заказ статустары: қабылданды, складқа түсті, комплектацияда, дайын, тиелді, жолда, жеткізілді, ішінара жеткізілді, бас тартты, возврат, жабылды.

# 13. Склад модулі

Тауар атауы, қалдық саны мен сомасы, сату бағасы, кіріс, шығыс, возврат, брак, списание, пересорт, просрочка және күнмен жететін қор. Себестоимость пен қаржылық нәтиже толық түрде Owner деңгейінде ғана.

# 14. Қорды болжау және Dead Stock

Орташа сату жылдамдығымен тауардың неше күнге жететінін есептеу және тапсырыс қажет болғанда ескерту. 30, 60 және 90 күн қозғалыссыз қалған тауарларға жеке Dead Stock есебі.

# 15. Бухгалтерия және Owner Finance Dashboard

1С деректері: касса, банк, түсім, шығын, дебиторка/кредиторка, реализация, возврат, закуп, себестоимость, жалақы, салық. Owner Finance Dashboard: выручка, себестоимость, валовая пайда мен маржа, шығындар, EBITDA, салық, таза пайда, таза рентабельность, ақша қозғалысы, дебиторка, кредиторка.

# 16. P and L

Формула: выручка – себестоимость = валовая прибыль; одан жалақы, логистика, аренда, жанармай, маркетинг, коммуналдық, банк және өзге операциялық шығындар алынады; операциялық пайдадан салықтар алынып таза пайда есептеледі. Нақты шығын құрылымы 1С бухгалтерімен бекітіледі.

# 17. Дебиторка және клиент карточкасы

Дебиторка: жалпы, просроченная, 1–7, 8–14, 15–30, 31–60, 60+ күн; клиент/ТП/супервайзер бойынша. Клиент карточкасы: атауы, мекенжай, телефон, GPS, ТП, супервайзер, қарыз, просрочка, соңғы/орташа заказ, айлық сату, возврат, SKU және визит тарихы. Owner маржа мен валовая пайданы, директор тек маржа пайызын көреді.

# 18. Қызметкер тиімділігі және тапсырмалар

Әр лауазымға KPI конструкторы: ТП — сату/маршрут, супервайзер — команда, экспедитор — жеткізу/ақша, склад — дәлдік/жылдамдық, бухгалтер — мерзім/қате. Қызметкер карточкасы: фото, лауазым, басшы, жоспар/факт, KPI, Score, динамика, рейтинг, кешігулер, тапсырмалар, ескертулер. Тапсырмаларда орындаушы, deadline, priority, файл, комментарий және статустар болады.

# 19. Уведомления және Проблемалар экраны

Автоматты хабарламалар: жоспардан қалу, возврат өсуі, дебиторка, төлем кешігуі, маршрутқа шықпау, аяқталмаған доставка, төмен қалдық, dead stock, маржа/валовая/таза пайда ауытқуы. Қаржылық хабарламалар Owner-ге, маржаға қатыстысы директорға ғана. Проблемалар экраны басым мәселелерді қызыл, сары, жасыл статуспен көрсетеді.

# 20. AI Assistant

AI сұрақтарға рөлге сай жауап береді: Owner барлық рұқсат етілген аналитиканы, директор сатылым мен маржаны, қалғандары тек өз операциялық деректерін сұрайды. AI RBAC-ты Backend деңгейінде сақтайды және рұқсатсыз валовая прибыль, маржа, таза пайданы ашпайды.

# 21. Sales Doctor интеграциясы

Кемінде: ТП, клиент, маршрут, визит, GPS, заказ және құрамы, SKU, сату сомасы, жоспар/факт, тарих, баға, KPI, возврат, қажет болса қалдық. Нақты механизм ресми API, web-service, database integration немесе Sales Doctor бекіткен басқа тәсілмен анықталады. Программист API құжаттамасы мен шарттарын алады.

# 22. 1С интеграциясы

1С — қаржы және ресми есептің негізгі көзі: номенклатура, контрагенттер, баға, себестоимость, қалдық, реализация, возврат, түсім, закуп, дебиторка/кредиторка, касса, банк, шығын, жалақы, салық. HTTP service, REST, OData, JSON, XML немесе конфигурацияның ресми механизмі қолданылады.

# 23. Data Source және синхронизация

Әр цифрға Master Source бекітіледі: қаржы, себестоимость, қалдық, реализация, дебиторка — 1С; GPS, визит, маршрут, заказ — Sales Doctor. Операциялық жаңарту 1–5 минут; 1С дерегі құжат өткізілген соң жаңарады. Қолмен Обновить батырмасы және соңғы синхронизация уақыты міндетті.

# 24. Интеграция қателері

Синхронизация тоқтағанда жүйе ескі цифрды үнсіз жаңа ретінде бермейді. Соңғы жаңарту уақыты көрсетіледі, Admin-ға ескерту жіберіледі және Integration Log жүргізіледі.

# 25. Қауіпсіздік

HTTPS, пароль hash, RBAC, Owner және негізгі басшыларға 2FA, session/device control, audit log, backup және API authentication. Қаржылық құқық интерфейспен ғана емес, Backend/API деңгейінде де қорғалады.

# 26. Audit Log және экспорт

Кім, қашан, нені қарады/қосты/өзгертті/жойды — сақталады; құпия бөлімге кіру де журналға жазылады. Негізгі есептер Excel және PDF-ке экспортталады. Экспорт құрамына рұқсатсыз дерек мүлде түспеуі тиіс.

# 27. Жалпы фильтрлер және Бір экран принципі

Фильтрлер: филиал, қала, супервайзер, ТП, клиент, бренд, категория, SKU, склад, дата, команда. Owner басты бетінде сатылым, валовая пайда, маржа, таза пайда, ақша, дебиторка, қойма, жоспар, қызметкерлер тиімділігі және негізгі проблемалар бір экранда көрінеді; деталь цифрды басқанда ашылады.

# 28. MVP Бірінші кезең

1С және Sales Doctor интеграциясы, Owner Dashboard, сату, валовая пайда, маржа, таза пайда, дебиторка, склад, ТП/супервайзер KPI, GPS/визит аналитикасы, рейтинг, уведомления, Web Admin және RBAC.

# 29. Екінші және үшінші кезең

Екінші кезең: водитель-экспедитор, толық склад, task management, AI, прогноз, аномалия, мотивация, бонус, толық Performance Management. Үшінші кезең: AI күнделікті анализ жасап, Owner-ге және директорға рөліне сай басқарушылық қорытынды береді.

# 30. Техникалық архитектура

Масштабталатын API-first архитектура: mobile және web ортақ Backend-пен, 1С және Sales Doctor-дан тәуелсіз интерфейстермен, backup және logging-пен. Backend API Swagger/OpenAPI форматында құжатталады.

# 31. Жобаның иелігі

Тапсырыс берушіге Source Code, Database structure, API documentation, server/admin access, deployment және backup нұсқаулықтары, интеграция құжаттамасы мен исходниктері, mobile/web source, барлық техникалық доступтар және Git repository беріледі. Негізгі аккаунттар Sapar Trade атына тіркеледі.

# 32. Acceptance Criteria

1С және Sales Doctor деректері автоматты келеді; көрсеткіштер бастапқы жүйелермен сәйкес; валовая пайда, маржа, таза пайда дұрыс есептеледі; RBAC және API қорғанысы жұмыс істейді; рөлдер құпия ақпаратты көрмейді; integration log, backup, audit log, mobile және web ашылуы тексеріледі.

# 33. Программист бастар алдындағы сұрақтар

Технологиялар, Backend, Database, Mobile/Web stack, сервер, 1С және Sales Doctor интеграциясы, API қолжетімділігі, 1С конфигурациясы, синхронизация жиілігі, backup/recovery, source ownership, қолдау, RBAC және API қорғанысы бойынша жазбаша жауап беріледі.

# 34. Негізгі бизнес нәтижесі

Sapar Trade иесі телефоннан бірнеше минутта: қанша сатты, валовая пайда, маржа, таза пайда, ақша, дебиторка, қойма, тауар динамикасы, қызметкер мен бөлім тиімділігі және қай жерде араласу керегін көреді.

# 35. Негізгі концепция

1С = қаржы және ресми есеп. Sales Doctor = далалық сату, заказ, маршрут, визит. Sapar Trade App = басқару, аналитика, бақылау, KPI және шешім қабылдау орталығы.
