# ТЗ: «Система управления» на реальных данных 1С

Версия 1.1 · 28.10.2026 · статус: **Этап A сделан и опубликован** (ответы: демо удалено; ТП = основной менеджер покупателя; план вводится в приложении; Экспедиторы — «не подключено»)

## 1. Цель
«Система управления» (владелец, директор, супервайзер, ТП, склад, бухгалтер) показывает **настоящие цифры из 1С** вместо придуманных. Вход — личный логин и пароль сотрудника, права проверяет сервер. Внешний вид и экраны сохраняются.

## 2. Что есть сейчас
- Данные из 1С уже приходят на сервер: товары (1203), клиенты (8329) с основным менеджером, склад (1), цены (14 типов), остатки, продажи и себестоимость по дням, долги клиентов.
- «Рабочий вход» уже показывает их на простых экранах.
- «Система управления» — богатые экраны, но на демо-данных и с демо-паролем `1234`.

## 3. Решение
Один вход для сотрудников: **«Система управления»** с личным логином и паролем (как в «Рабочем входе»). Роль берётся с сервера. Экраны «Системы управления» получают данные с сервера. «Рабочий вход» сливается с ней.

## 4. Экраны — что станет реальным

### Этап A — данные уже есть в 1С (делаем сейчас)
| Экран | Что показываем | Кто видит |
|---|---|---|
| Главная | Выручка, маржа %, валовая прибыль, склад по цене продажи, дебиторка, просрочка; сравнение с прошлым периодом; график по дням | по правам роли |
| Продажи | По дням, товарам, группам товаров, клиентам, менеджерам; сравнение периодов; выгрузка CSV | владелец, директор, бухгалтер; ТП/супервайзер — свои |
| Команда | Рейтинг торговых представителей (менеджер клиента в 1С): выручка, число клиентов, средняя продажа, долг и просрочка их клиентов; план/факт — если план введён в приложении | владелец, директор, супервайзер (своя команда) |
| Клиенты | Список, долг, «возраст долга» (0–7, 8–14, 15–30, 30+ дней), последняя покупка, «спящие» клиенты | по правам |
| Склад | Остатки, сумма, отрицательные, без цены, неликвид (нет продаж 30/60/90 дней), на сколько дней хватит | владелец, директор, склад |
| Финансы | Выручка, себестоимость, валовая прибыль и маржа по дням и группам | только владелец |
| Проблемы | Считаются из реальных данных: просрочка, отрицательные остатки, нет цены, неликвид, «данные устарели», ТП без продаж | по правам |
| Задачи | Хранятся на сервере, назначаются сотрудникам | все |
| Система | Статус загрузки из 1С, журнал, сотрудники, журнал действий | владелец, бухгалтер |
| AI | Пока подсказки по правилам на реальных цифрах (нейросеть — отдельный этап) | по правам |

### Этап B — нужны новые запросы в 1С
- Касса и банк (поступления и выплаты), расходы, чистая прибыль (P&L).
- Возвраты отдельной строкой, заказы покупателей.
- Перед разработкой — диагностика `-Probe` по нужным регистрам и ответ бухгалтера, где ведутся расходы.

### Этап C — нет источника данных
- **Экспедиторы (GPS)** и **визиты/маршруты ТП** — раньше планировались из Sales Doctor, он не используется. Нужен отдельный источник (приложение водителя с GPS или трекер). До этого вкладка скрыта или помечена «не подключено».
- **План продаж** — в 1С не ведётся (уточнить); вводится в приложении владельцем/директором по месяцам на ТП.

## 5. Сервер (новое)
- `GET /api/dashboard` — добавить прошлый период для сравнения.
- `GET /api/sales?group=group|manager` — группы товаров и менеджеры.
- `GET /api/team` — рейтинг ТП по менеджеру клиента.
- `GET /api/clients` — возраст долга, спящие клиенты.
- `GET /api/stock` — неликвид, дни запаса (по истории продаж).
- `GET /api/finance` — только владелец.
- `GET /api/problems` — рассчитанные проблемы по правам.
- `GET/POST/PATCH /api/tasks`, таблица `tasks`; `GET/PUT /api/plans`, таблица `sales_plans`.
- Права — на сервере, как сейчас: себестоимость и валовая только владельцу, маржа % владельцу и директору, ТП и супервайзер — только свои клиенты.

## 6. Сайт
- Вход «Система управления» → личный логин/пароль (сервер). Демо-пароль `1234` убирается.
- Экраны `mg_*` читают данные из API вместо демо-генератора; при отсутствии данных — понятное «нет данных», а не выдуманные цифры.
- Плашка «данные устарели» — по реальному времени последней загрузки из 1С.

## 7. Критерии приёмки
- В «Системе управления» нет ни одной придуманной цифры: всё либо из 1С, либо помечено «нет данных/не подключено».
- Цифры на Главной совпадают с отчётом 1С «Валовая прибыль» и «Ведомость по взаиморасчётам» за тот же период.
- Директор и ТП не получают себестоимость и валовую ни в одном ответе сервера (автотесты).
- Работает на телефоне и компьютере, RU/ҚАЗ.
